# Pasta de Planos de Teste (`plano-teste/`)

Esta pasta armazena os planos de teste gerados pelo **Analista de Testes (Agent 02)** (`analista-testes`).

## Convenção de Nomenclatura
- `plano-teste/{modulo}-plan.md`

## Padrão Estrutural
- **Passos Numerados:** Todos os testes usam sequência lógica numerada (1, 2, 3...).
- **Matriz de Rastreabilidade:** Tabela final relacionando 100% dos Critérios de Aceite (CA) aos Casos de Teste (CT).
